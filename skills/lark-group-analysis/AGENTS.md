# AGENTS.md — Lark Group Analysis

## 自然语言命令映射

AI Agent 根据用户的自然语言表述，映射到具体的命令行执行。

### 命令映射表

| 用户表述 | 实际执行 |
|---------|---------|
| "分析一下 TRAE 群" | `group_analysis.py --name "TRAE"` |
| "看看这个群的活跃度" | `group_analysis.py --name <群名> --top 10` |
| "生成群画像" | `group_analysis.py --name <群名> --format html` |
| "谁是这个群最活跃的人" | `group_analysis.py --name <群名> --top 1` |
| "分析群话题" | `group_analysis.py --name <群名> --topics` |
| "查看群成员" | `group_analysis.py --name <群名> --members` |
| "刷新重新分析" | `group_analysis.py --name <群名> --refresh` |

## 执行流程

### 1. 解析用户意图

当用户说"分析 XX 群"时：
1. 提取群名称关键词
2. 搜索匹配的群聊
3. 获取群聊数据
4. 生成分析报告

### 2. 输出格式

支持两种输出格式：

**Markdown 格式（默认）**
```markdown
# 📊 群聊分析报告 — [群名称]

## 群基本信息
- 群成员: XX 人
- 消息总数: XXX 条
- 分析周期: 最近 XX 天

## 活跃度排名
1. @张三 - 128 条
2. @李四 - 95 条
...

## 话题分布
- 技术讨论: 45%
- 闲聊: 30%
- 公告: 15%
...
```

**HTML 格式**
- 生成独立的 HTML 报告文件
- 支持可视化图表
- 可在浏览器中打开

## 错误处理

| 错误情况 | 处理方式 |
|---------|---------|
| 群不存在 | 提示用户检查群名，提供模糊搜索建议 |
| 无权限访问 | 提示需要群管理员权限 |
| 消息获取失败 | 使用缓存数据（如果有），否则报错 |
| 群太冷清（<10条消息） | 提示数据不足以生成分析 |

## 示例对话

### 用户
帮我分析一下 "TRAE 官方群" 这个群
