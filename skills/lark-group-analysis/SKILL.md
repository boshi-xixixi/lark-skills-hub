# Lark Group Analysis — 群聊分析

## 功能概述

Lark Group Analysis 是一个用于分析飞书群聊特征和成员互动模式的 Skill。通过深度分析群聊消息，可以了解：

- 群的规模、类型和活跃度
- 群成员活跃度排名
- 话题分布和讨论热点
- 群互动时间规律
- 群氛围评估

## 核心功能

### 1. 群聊搜索与选择
- 通过群名称搜索群聊
- 支持模糊匹配
- 列出匹配的群聊列表供选择

### 2. 群聊数据获取
- 获取群成员列表
- 获取群消息历史（支持分页）
- 时间范围过滤（最近 N 天）

### 3. 群聊画像生成
分析并生成群聊画像报告，包括：

**基本信息**
- 群名称、群ID
- 群成员数量
- 消息总数
- 群类型（内部/外部）

**活跃度分析**
- 成员活跃度排名 Top N
- 人均消息数
- 日均消息数
- 消息趋势

**话题分析**
- 高频词汇统计
- 话题分类（技术/休闲/公告等）
- @提及统计

**时间规律**
- 活跃时段分布
- 工作时间 vs 非工作时间
- 周末 vs 工作日

**氛围评估**
- 表情/贴纸使用统计
- 互动回应率
- 群健康度评分

## 使用场景

1. **了解新群** - 刚加入一个群，想快速了解这个群的活跃度和话题
2. **关系维护** - 分析和某人的共同群聊，了解社交圈
3. **社群运营** - 运营者分析社群活跃度，制定运营策略
4. **团队诊断** - 团队负责人了解团队沟通模式和效率

## 技术实现

- 使用 `lark-cli im +chats-list` 获取群列表
- 使用 `lark-cli im +chat-members` 获取群成员
- 使用 `lark-cli im +messages-search` 或 `+chat-messages-list` 获取消息
- 本地缓存分析结果
- 支持 Markdown 和 HTML 输出格式

## 依赖

- lark-cli 已安装并完成认证
