# Lark Profile - 用户画像分析

## 简介

`lark-profile` 是一个智能用户画像分析 Skill，通过分析飞书聊天记录来判断某个用户是什么人、与你的关系如何。

## 核心功能

1. **用户搜索** - 通过姓名搜索飞书用户
2. **聊天记录分析** - 获取与目标用户的聊天历史
3. **画像生成** - 分析并生成用户画像报告，包括：
   - 基本信息（姓名、职位、部门等）
   - 关系分析（沟通频率、亲密度、互动模式）
   - 话题分析（主要讨论什么）
   - 互动时间规律（什么时候联系最多）
   - 关系评估（工作关系/私人关系/陌生/密切等）

## 使用方式

### 命令行使用

```bash
# 搜索并分析用户画像
python3 profile.py --name "张三"

# 指定时间范围分析（最近30天）
python3 profile.py --name "张三" --days 30

# 生成 HTML 报告
python3 profile.py --name "张三" --format html

# 查看用户关系摘要
python3 profile.py --name "张三" --summary

# 列出所有分析过的联系人
python3 profile.py --list
```

### AI Agent 使用

在 AI Agent 对话中，直接使用自然语言：

- "帮我分析一下张三这个人的画像"
- "查看我和李四的聊天记录分析"

- "分析一下这个人的信息"

## 技术实现

- 使用 `lark-cli contact +search-user` 搜索用户
- 使用 `lark-cli im +messages-search` 获取聊天记录
- 使用 `lark-cli im +chat-messages-list` 获取私聊详情
- 本地缓存分析结果到 `~/.lark-profile/`

## 缓存策略

- 用户信息缓存: 24 小时
- 聊天记录缓存: 12 小时
- 分析报告缓存: 6 小时

## 权限要求

- 通讯录访问权限 (contact)
- 消息读取权限 (im:message:readonly)
- 用户身份权限 (contact:user.id:readonly)
